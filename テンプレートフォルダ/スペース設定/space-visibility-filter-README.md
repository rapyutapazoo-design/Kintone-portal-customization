# ポータルのスペース一覧 表示制御（`space-visibility-filter.js`）

Kintone のポータルに表示される「スペース」一覧から、**ホワイトリストに登録していない公開スペースを非表示**にするカスタマイズです。PC・モバイルの両方に対応します。**全ユーザーに同じルールを適用**します（管理者等の特別扱いはありません）。

マンションのコミュニティ用スペースは**ハブスペース経由**でアクセスさせたいため、ポータルの一覧には出しません。スペース自体は公開のままなので、ハブスペースのリンクから誰でも自由に参加できます。また、**すでに参加しているスペースはホワイトリストに関わらず表示**されるため、一度参加すれば自分のポータルからすぐにアクセスできます。

> [!IMPORTANT]
> **これはセキュリティ機能ではありません。** ポータルの見た目から消えるだけで、URL 直打ち・全体検索・通知からは引き続きアクセスできます。「参加は自由にさせたいが、ポータルには並べたくない」という用途のための UI 整理です。

---

## 表示ルール

上から順に評価し、1つでも当てはまれば**表示**します。どれにも当てはまらない公開スペースだけが非表示になります。

| # | 条件 | 結果 |
|---|------|------|
| 1 | `VISIBLE_SPACE_IDS` に含まれる | 表示 |
| 2 | `ALWAYS_KEEP_SPACE_IDS` に含まれる | 表示 |
| 3 | 鍵マーク付き（非公開スペース） | 表示 |
| 4 | **自分が参加済み** | 表示 |
| 5 | スペース ID を判定できなかった | 表示（安全側に倒す） |
| — | 上記以外の公開スペース | **非表示** |

非公開スペースを対象外にしているのは、Kintone 標準で**参加者にしか表示されない**ためです。こちらで隠す必要がありません。

### 「参加済み」の判定方法（PC とモバイルで異なります）

| | 判定方法 | 通信 |
|---|---|---|
| **モバイル** | DOM 上の「参加中」バッジ（クラス名）で同期的に判定 | なし |
| **PC** | 参加状態を示す DOM 上の手がかりが実機調査で見つからなかったため、**ホワイトリスト外・非公開でもない「非表示候補」に絞って** kintone REST API（`/k/v1/space/members.json`）でメンバーかどうかを確認 | あり（候補のみ） |

PC は API 通信が発生する分、**一瞬「非表示」の状態から遅れて表示される**ことがあります（表示→非表示に戻ることはありません）。ホワイトリスト・鍵付きスペースには API が呼ばれないため、通信範囲は最小限に抑えています。

---

## 設定

`space-visibility-filter.js` 冒頭の `CONFIG` だけを編集します。

| 設定項目 | 既定値 | 説明 |
|----------|--------|------|
| `VISIBLE_SPACE_IDS` | `['2', '3', '6', '16']` | ポータルに表示し続けるスペース ID。ここに無い公開スペースが隠れます |
| `KEEP_PRIVATE_SPACES` | `true` | 鍵マーク付きスペースを非表示の対象から外す |
| `ALWAYS_KEEP_SPACE_IDS` | `[]` | **保険**。鍵マークの自動判定が壊れたときの復旧用（後述） |
| `HIDE_WIDGET_WHEN_EMPTY` | `true` | 表示対象が 0 件ならスペースウィジェットごと隠す |
| `DEBUG` | `false` | `true` にすると判定結果をブラウザのコンソールに出力します |

### スペース ID の調べ方

対象スペースを開いたときの URL 末尾の数字がスペース ID です。

```text
https://<サブドメイン>.cybozu.com/k/#/space/16
                                            ^^ これがスペースID
```

### 新しいコミュニティ用スペースを追加するとき

**何もする必要はありません。** 新しく作った公開スペースは、ホワイトリストに無いため自動的にポータルから隠れます。逆に「ポータルにも並べたい」場合だけ、そのスペース ID を `VISIBLE_SPACE_IDS` に追加してください。なお、**参加さえすれば誰でもすぐにポータルに表示される**ため、多くの場合はホワイトリストへの追加自体が不要です。

## 導入手順

1. cybozu.com 共通管理 → **カスタマイズ／サービス連携** → **JavaScript / CSS でカスタマイズ**
2. **PC 用**の「JavaScript ファイル」に `space-visibility-filter.js` をアップロード
3. **モバイル用**の「JavaScript ファイル」にも**同じファイル**をアップロード
4. 保存後、ポータルを再読み込みして表示を確認

PC・モバイルの両方の処理が 1 ファイルに入っているため、登録するファイルは 1 つだけです。

## トラブルシューティング

### 鍵マーク付きのスペースがポータルから消えてしまった

Kintone 側の仕様変更で鍵マークの自動判定が効かなくなった可能性があります。**消えてしまった非公開スペースの ID を `ALWAYS_KEEP_SPACE_IDS` に追加**すると、その場で復旧できます。

```js
ALWAYS_KEEP_SPACE_IDS: ['your-space-id-1', 'your-space-id-2', 'your-space-id-3', 'your-space-id-4'],
```

そのうえで、下記「保守のポイント」のセレクタを実際の DOM に合わせて更新してください。

### 参加しているのに PC でだけ表示されない

- ブラウザの開発者ツールのコンソールで、`[space-visibility-filter]` から始まるログを確認してください（`DEBUG: true` にすると詳細が出ます）
- ネットワークタブで `space/members.json` への通信が成功しているか確認してください。**権限エラー等で失敗した場合は「非表示のまま」がフェイルセーフの仕様**です（隠したいスペースが誤って全員に見えてしまうより安全なため）
- `sessionStorage` に判定結果をキャッシュしています。参加した直後は反映されないことがあるため、**ページを再読み込み**してください

### 隠したいスペースが隠れない

- `DEBUG: true` にしてポータルを開き、コンソールの `[space-visibility-filter]` のログで判定結果を確認します
- そのスペースに**すでに参加していないか**を確認します（参加済みなら仕様通り表示されます）

### 何も起きない／一覧がずっと表示されない

本カスタマイズは**失敗したら何も隠さない**設計です。処理中にエラーが起きても、スペース一覧は Kintone 標準の状態で必ず表示されます（業務影響はありません）。

## 保守のポイント

Kintone の DOM 構造に依存する箇所は、ファイル内の `TARGETS` に集約しています。壊れた場合はここだけを直せば復旧できます（2026-08 時点の実機で確認）。

| | PC | モバイル |
|---|---|---|
| ウィジェット | `div.ocean-portal-space` | `div.gaia-mobile-v2-portal-spacewidget-container` |
| スペースのリンク | `a.gaia-argoui-spacescrollinglist-item` | `a.gaia-mobile-v2-ui-space-spacelist-item-link` |
| 鍵マーク | `span.gaia-argoui-spacescrollinglist-private` | `.gaia-mobile-v2-ui-space-spacelist-item-private-icon` |
| 参加中マーク | なし（API で確認） | `.gaia-mobile-v2-ui-space-spacelist-item-tag-joined` |
| href 形式 | `/k/#/space/16` | `/k/m/space/16` |

その他の設計上の要点:

- **スペース名には依存しません。** 判定は href から取り出したスペース ID のみで行うため、スペース名を変更しても壊れません
- **ちらつき防止**: スクリプト読み込み時に一覧を `visibility:hidden` にし、DOM だけで完結する判定（ホワイトリスト・鍵マーク・モバイルの参加中タグ）が終わった時点で戻します。2 秒のタイムアウトを設けているため、隠れたままになることはありません。PC の API 確認はこのタイミングより後に完了するため、ちらつき防止の対象には含まれません（表示が後から追加されるだけで、一覧自体が隠れっぱなしになることはありません）
- **遅延読み込み対応**: `MutationObserver` でスペース一覧の増減を監視し、後から読み込まれたスペースにも自動で適用します（参加済み確認 API も再度呼ばれます）
- **PC のメンバーシップ確認**: `/k/v1/space/members.json` の呼び出し対象はホワイトリスト外・非公開でもないスペースのみ。結果は `sessionStorage` にスペース単位でキャッシュし、同一セッション内の重複呼び出しを避けます。API が失敗した場合は非表示のまま維持します（キャッシュはしないため、次回アクセス時に再度確認します）
- 鍵マーク・参加中マークの判定は、実機で確認したクラス名を第一候補にしつつ、class 名に `private` / `lock` / `joined` を含む要素も拾うことで仕様変更への耐性を持たせています
- **除外機構はありません。** 以前はデジタル委員会・Administrators を非表示処理の対象外にする仕組みがありましたが、「全ユーザーに同じルールを適用する」という方針に変更したため撤去しました。参加済みなら誰でも表示される仕組みで代替しています

## 公開リポジトリでの取り扱い

本リポジトリはパブリックです。このファイルには**スペース ID**が実値で入っています。単体では意味を持たない識別子で、サブドメインなどの接続情報は含みませんが、実値を出したくない場合は `テンプレートフォルダ/` にプレースホルダー版を置き、本ファイルは非公開プロジェクト側で管理する運用に切り替えてください。
