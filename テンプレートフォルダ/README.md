# テンプレートフォルダ

このフォルダには、リポジトリ本体（適用ファイル・実値入り）から**固有情報をプレースホルダーに置き換えたテンプレート**が入っています。他の組織でこのカスタマイズを流用する場合は、このフォルダの内容をベースにしてください。

---

## 📂 このフォルダの位置づけ

- 実際のアプリID・組織コード・グループコードなど**固有情報を含む実値ファイルは、本リポジトリには置きません**（動作確認は各機能の開発プロジェクト側・非公開で行います）。
- **`テンプレートフォルダ/`（このフォルダ）** ＝ 本リポジトリで公開する唯一の配布物です。実値はすべてプレースホルダーに置き換わっています。

このフォルダは自動生成ではなく、**直接編集して保守**してください（`scripts/generate-template.js` は現在対象なし。実値ファイルからの自動生成が必要な機能が今後増えた場合のための土台として残しています）。

---

## 🔧 含まれるファイルとプレースホルダー

### `ショトカボタン/portal-shortcut.js`

`appList`（ポータルに配置するアプリの一覧）が以下のプレースホルダーになっています。

```js
var appList = [
    { id: 'your-app-id-1', name: 'アプリ名1' },
    { id: 'your-app-id-2', name: 'アプリ名2' },
    { id: 'your-app-id-3', name: 'アプリ名3' },
    { id: 'your-app-id-4', name: 'アプリ名4' }
];
```

- `your-app-id-N` … 実際に配置したいKintoneアプリの**アプリID**（数値）に書き換えてください。
- `アプリ名N` … ポータルに表示する**ボタンの表示名**（絵文字を含めても構いません）に書き換えてください。
- 配置するアプリの数に応じて、行を自由に増減できます。
- この `appList` は**ユーザーが ⚙️ ボタンで個人設定を行っていない場合に表示される既定値**です。既定値の変更は、これまでどおりこのファイルを書き換えて再配置する運用（自動化はしていません）です。

#### ⚙️ 個人カスタマイズ機能について

ポータル上部の 🎨（色変更）・🔲（形変更）に加えて、⚙️ ボタンからユーザー本人がショートカットの**遷移先アプリ・表示名・並び順・個数（4〜6個）**を編集できます。

- 設定はブラウザの `localStorage`（キー: `kintone_portal_shortcuts_<ログインユーザーID>`。ユーザーIDが取得できない場合のフォールバックキー: `kintone_portal_shortcuts_default`）に保存されます。
- **端末・ブラウザ間で同期されません**（localStorage はブラウザ・端末ごとに独立しているため、他の端末や別ブラウザ、シークレットウィンドウでは常に既定の `appList` が表示されます）。
- 保存データが存在しない・壊れている・件数が4〜6個の範囲外などの場合は、常に既定の `appList` へ自動フォールバックします（ポータルが空表示になることはありません）。
- アプリ一覧の取得（Kintone REST API `/k/v1/apps.json`）は ⚙️ モーダルを開いたときのみ行われ、通常のポータル表示時には実行されません。

### `プロフィール閲覧制限/プロフィール閲覧制限カスタマイズ/config.js`

プロフィール閲覧を許可する組織・グループが以下のプレースホルダーになっています。

```js
allowedOrgs: ['YOUR_ORG_CODE'],
allowedGroups: ['YOUR_GROUP_CODE'],
```

- `YOUR_ORG_CODE` … 閲覧を許可する**組織のコードまたは名前**に書き換えてください。
- `YOUR_GROUP_CODE` … 閲覧を許可する**グループのコードまたは名前**に書き換えてください。
- 複数指定する場合は配列にカンマ区切りで追加できます（例: `['YOUR_ORG_CODE_1', 'YOUR_ORG_CODE_2']`）。

`main.js`・`restriction.css` は固有情報を含まないため、無変更でそのまま利用できます。

## ⚙️ 導入方法

1. このフォルダの各ファイルをコピーし、上記のプレースホルダーを実際の値に書き換えます。
2. Kintoneのシステム管理から「JavaScript / CSS でカスタマイズ」を開き、書き換えたファイルを登録します。
3. リポジトリ本体（`Kintone全体カスタマイズ`）の各READMEに記載の導入手順・注意事項もあわせてご確認ください。
