# スペース設定

Kintone の**スペース**まわりのカスタマイズをまとめたフォルダです。マンションのコミュニティ用スペースを、ハブスペース経由で見つけて参加してもらうための2つの機能で構成されています。

| ファイル | 機能 | 対象画面 | ドキュメント |
|---|---|---|---|
| [`space-visibility-filter.js`](space-visibility-filter.js) | ポータルのスペース一覧 表示制御 | ポータル（PC・モバイル） | [詳細](space-visibility-filter-README.md) |
| [`space-join-button.js`](space-join-button.js) | スペースの参加・退会ボタン | スペーストップ（PC・モバイル） | [詳細](space-join-button-README.md) |

いずれも cybozu.com 共通管理の **JavaScript / CSS カスタマイズ**に、**PC 用・モバイル用の両方**へ同じファイルを登録して使います。

---

## 2つの機能の関係

```text
ポータル                          スペーストップ
┌──────────────────────┐         ┌──────────────────────┐
│ スペース一覧          │         │ ハブスペース          │
│  ・ハブスペース    ←──┼─ 入口 ─→│  ・1号棟コミュニティ  │
│  ・参加済みスペース   │         │  ・防災ボランティア   │──┐
│  （未参加のコミュニ   │         └──────────────────────┘  │
│    ティは非表示）     │                                    │
└──────────────────────┘         ┌──────────────────────┐  │
          ↑                       │ 1号棟コミュニティ     │←─┘
          │                       │ [＋ このスペースに    │
          └── 参加すると表示 ──────│    参加する]          │
                                  └──────────────────────┘
```

1. **`space-visibility-filter.js`** が、ホワイトリスト外の未参加スペースをポータルから隠します。コミュニティ用スペースは一覧に並ばず、ハブスペース経由でたどり着く導線に一本化されます
2. **`space-join-button.js`** が、スペーストップに参加ボタンを出します。Kintone 標準では「…」メニューの中にしかなく気づけないため、参加したつもりで参加できていない事故を防ぎます
3. 参加すると、そのスペースはポータルの一覧にも表示されるようになります

---

## 運用上の注意

> [!IMPORTANT]
> **表示制御はセキュリティ機能ではありません。** ポータルの見た目から消えるだけで、URL 直打ち・全体検索からは引き続きアクセスできます。スペースは公開のままで、誰でも自由に参加できる状態を保つための UI 整理です。

> [!TIP]
> **コミュニティ用スペースには `everyone` をメンバーに入れないでください。** 入れると全員が「暗黙的メンバー」になり、参加ボタンが出ないうえ、個々の住民が退会することもできなくなります（Kintone の仕様上、組織・グループ経由のメンバーは個人単位で抜けられません）。詳細は[参加・退会ボタンのドキュメント](space-join-button-README.md)を参照してください。
