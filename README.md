# Kintone Portal Customization

Kintone のポータル画面をカスタマイズする JavaScript の管理リポジトリです。
本リポジトリは、ポータル上部に表示する**ショートカットボタン機能**を、機能ごとに分割・管理することを目的としています。

---

## 📂 ファイル構成

```text
Kintone-portal-customization/   ← 親（リポジトリルート）
├── README.md                   ← 本ファイル（導入・運用手順）
└── ショトカボタン/              ← 子モジュール: ショートカット機能
    └── portal-shortcut.js       ← ショートカットボタン本体
```

今後フォントサイズ変更機能などを分割・移管する場合も、同様に親ルート配下の子フォルダとして追加していきます。

---

## 🚀 機能概要（`ショトカボタン/portal-shortcut.js`）

Kintone ポータル画面の上部に、よく使うアプリへのショートカットボタンを配置します。

- **アプリショートカットボタン**
  - 現在の配置一覧:
    1. `📋 アンケート`（アプリID: 47）
    2. `📮 意見書`（アプリID: 48）
    3. `🕒 施設予約`（アプリID: 38）
    4. `📅 カレンダー`（アプリID: 72）
  - ボタンの遷移先は各アプリの `/k/{アプリID}/` です。配置・名称・アイコンは `appList` 配列（`portal-shortcut.js` 内）で変更できます。
- **カラーテーマ変更（🎨）・形状変更（🔲）**
  - ボタンのグラデーション配色（navy / green / purple / standard）と角丸形状（capsule / rounded）を切り替えできます。
  - 選択値はブラウザの `localStorage`（`kintone_portal_theme_idx` / `kintone_portal_shape_idx`）に個別保存されます。
- **PC / モバイル両対応**（`portal.show` / `mobile.portal.show`）。

## 🧩 共有コーディネーター `window.PortalCustomize`

ポータル上部のコンテナと「マウントスロット」を提供する軽量な共有ロジックです。各機能ファイルは「自分のボタンを所定スロットに挿す」ことだけに責務を限定でき、**読み込み順に依存せず**に協調動作します。

- **冪等初期化**: コンテナは一度だけ生成されます（重複防止 ID: `my-custom-app-container`）。
- **提供スロット**:
  - スロット1: ショートカットボタン群 … `addShortcutItem(el)`
  - スロット2: 色 / 形ボタン … `addConfigItem(el)`
  - スロット3: フォントボタン群（`configContainer` 右寄せ）… 本リポジトリでは未使用。将来フォント機能を分割した際に `getConfigContainer()` を取得してマウントする想定です。

> フォント設定（`localStorage` キー・`kintone-font-size-changed` イベント）はフォント側の所有物であり、`portal-shortcut.js` からは一切操作しません。

## ⚙️ 導入方法

1. Kintone のシステム管理から「JavaScript / CSS でカスタマイズ」を開きます。
2. `ショトカボタン/portal-shortcut.js` を「PC 用の JavaScript ファイル」および「スマートフォン用の JavaScript ファイル」にアップロードします。
3. 設定を保存し、ポータル画面を再読み込みして動作を確認してください。

---

## ⚠️ 運用・保守上の注意

- **既存ファイルとの同時適用は避けてください。**
  本ファイルは重複防止 ID に既存ファイルと同一の `my-custom-app-container` を使用します。旧来のポータルカスタマイズファイルと**同時に適用すると、先に実行された側のみが描画され、ショートカットの二重表示や色/形ボタンの欠落が発生**します。旧ファイルを置き換えてから適用してください。
- **DOM 操作に関する注意**: Kintone 本体のアップデートにより DOM 構造が変わると、動作に影響が出る可能性があります。
- 本リポジトリには API キー等の機微情報は含めません。
